# Microsoft Integration

This guide will walk you through setting up Microsoft integrations for your application.

## Prerequisites

Before you begin, make sure you have:

- A Microsoft Azure account
- Admin access to your Microsoft 365 tenant
- Basic understanding of OAuth 2.0

## Step 1: Register Your Application

1. Go to the [Azure Portal](https://portal.azure.com)
2. Navigate to **Azure Active Directory**
3. Click on **App registrations**
4. Select **New registration**

![Azure App Registration Screen](/images/help/integrations/microsoft/image2.png)

When you reach the app registration screen, you'll see a form like the one above. Fill in your application name and select the appropriate account types for your use case.

## Step 2: Configure Permissions

Add the following permissions to your application:

- `User.Read`
- `Mail.Read`
- `Calendars.Read`

![Microsoft API Permissions Setup](/images/help/integrations/microsoft/image1.png)

The API permissions screen allows you to grant the necessary access rights for your integration. Make sure to click "Grant admin consent" after adding all required permissions.

## Troubleshooting

If you encounter issues, check the following:

- Ensure your redirect URL is correctly configured
- Verify that all required permissions are granted
- Check that your client secret hasn't expired

## Next Steps

Once your Microsoft integration is set up, you can:

- Set up automated email sync
- Configure calendar integration
- Enable Teams notifications
