When your forecast moves, you want to know why. **Forecast updates** lists each change to an opportunity in the forecast and shows how much it moved the total.

## The Forecast updates panel

The panel sits in the top right of the Forecast dashboard and shows the most recent changes.

<img src="/images/help/dashboard/forecast/updates-block.jpg" alt="Forecast updates panel listing recent changes to opportunities" width="1200" height="680" />

The heading sums up the past week. For example, **<DemoValue path="forecast.sevenDaysAgo" /> → <DemoValue path="forecast.total" /> ↓ last 7 days** means the forecast was <DemoValue path="forecast.sevenDaysAgo" /> seven days ago and is <DemoValue path="forecast.total" /> now.

## Reading an update

Each row is one change to one opportunity:

| Column | What it shows |
| ------ | ------------- |
| **Updated on** | The date the change happened. |
| **What happened?** | The old value on the left and the new value on the right. A calendar icon means the close date changed; a dollar icon means the deal value changed. |
| **Opportunity name** | The opportunity that changed. Click the name to open it in a new tab. |
| **Impact** | How much this change moved the forecast. Green (+) increased it; red (-) reduced it. |
| **Forecast** | The forecast total right after this change. |

### Common changes

- **Value changed**: the deal amount went up or down, for example **$31.1K → $4.7K**.
- **Close date moved**: the deal's expected close date changed, for example **8/13/26 → 10/21/26**. If the new date moves a deal into or out of the selected quarter, it's added to or removed from the forecast.

## Seeing the full history

Click **View +N updates** at the bottom of the panel to open the full list for the selected quarter. The list scrolls and shows every update to opportunities closing in that quarter, newest first.

<img src="/images/help/dashboard/forecast/updates-panel.jpg" alt="Full Forecast updates list for opportunities closing in Q4 2026" width="1600" height="1069" />

Close the list with the **×** in the top-right corner.

## Tips

- After a big drop in the forecast, check here first to find the few deals that caused it.
- If the same opportunity appears many times, it has been edited often. That can mean the deal is unstable and worth a closer look.
- Pick a single pipeline in the **All pipelines** menu to see updates for that pipeline only.
